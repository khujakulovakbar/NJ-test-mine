# NJ: Банковские кредиты (nj_bank_loans) — версия 19.0.1.2.2

Модуль для Odoo 19 Enterprise. Раздел **Accounting → Accounting → Кредиты** (после Assets & Liabilities).

## Что нового в 1.2.2
- **БГ (комиссия банковской гарантии) — отдельной колонкой**, как в Excel: в «Дневном виде», «По месяцам» (список и сводная — мера «БГ») и в карточке кредита. «Погашен % / Проценты» теперь только проценты; «Всего» = долг + проценты + БГ.
- Сверка с исходным Excel 28.10.2026: 470 платежей, 9 829 дней, 339 месяцев, 21 ставка, остатки на 28.10 — совпадают до цента (файл «Кредиты_сверка_Excel_Odoo_28.10.xlsx»).

## Что нового в 1.2.1
- **По месяцам (сводная):** строки Банк → Кредит — «+» открывает следующий уровень одним нажатием; колонки по годам (год раскрывается до квартала / месяца из заголовка); меры **Осн. долг / Проценты / Всего**.
- **Графики (кнопка 📊 справа вверху каждого отчёта):** Кредиты — остаток по кредитам по убыванию, цвет по банку; По месяцам — платежи по месяцам по банкам (в «Меры» — долг, проценты или всего); План-факт — плановые платежи по месяцам: долг и проценты стопкой. Отдельный график «Остаток долга по банкам» — линии по банкам.

## Что нового в 1.2.0
- **Просрочка считается как остаток долга, а не вся плановая строка.** Долг и проценты зачитываются между собой: когда 1С относит часть процентов на счёт кредита (случай K-02), деньги до банка дошли — это не просрочка. Разница меньше 1 % от самого крупного планового платежа считается курсовым округлением и видна только в план-факте.
- **Всплывающие окна — один раз на событие**, а не каждый день. Платёж объявляется максимум дважды: жёлтым при входе в окно «Скоро» и красным при входе в «Срочно» — это разные события.
- Цвета: 🔴 просрочка, списание пени, платёж через 0–3 дня; 🟡 платёж через 4–7 дней; 🟢 досрочное погашение с экономией.
- «Скоро» по умолчанию 14 → **7 дней** (настраивается).
- Новая таблица показанных уведомлений (nj.loan.notice) — по пользователю и событию.

## Что нового в 1.1.1
- Исправление по итогам теста на копии рабочей базы: дневная выписка банка проводится **одной проводкой со множеством строк**. Слово «пеня» в одной строке больше не делает пенями соседние строки (зарплата, займы, оплаты поставщикам). Текст и контрагент теперь читаются по самой строке; строки соседей учитываются только у простой проводки (до 4 строк).
- Предфильтр по строке до разбора текста — меньше строк на обработку.

## Что нового в 1.1.0
- Меню сокращено до 4 пунктов: Обзор, Кредиты, План-факт, По месяцам. Остальные отчёты — вкладки и кнопки.
- **Пени по кредитам**: списания банком с расчётного счёта со словом пени / штраф / неустойка (настраивается). Вид «Пеня», в план-факт не входит.
- **Просрочка**: статус «Просрочено», сумма, дата начала, стоимость дня просрочки (поле «Пеня, % в день» в карточке кредита).
- **Досрочное погашение**: автоматически из выписки; график пересчитывается; экономия процентов показывается на Обзоре и в карточке («События»). Статус «Расчётный» до загрузки графика банка.
- **Получатели уведомлений**: в настройках Бухгалтерии — кто получает: платёж скоро, просрочка, списана пеня, досрочное погашение. Пусто — только CFO.
- **Загрузка Excel**: кредиты, уже изменённые в Odoo (досрочное, график банка), не перезаписываются — галочка снята, колонка «Внимание».

## Установка / обновление
1. Загрузить файлы модуля в ветку (папку `nj_bank_loans`).
2. Дождаться сборки Odoo.sh (статус Success).
3. Apps → Update Apps List → установить или обновить «NJ: Банковские кредиты».
4. Назначить группы: Просмотр / Казначей / Администратор (Settings → Users).
5. Настройки → блоки «Кредиты: …»: получатели, слова пени, окно досрочного, дата «Выписки загружены с».

## Зависимости
account, mail. Python: openpyxl (есть в Odoo).

## Проверка после установки
- Обзор: долг, платежи 30 дней, плитки «Потери от просрочек» и «Экономия от досрочных».
- План-факт за месяц: разница по процентам и тип разницы.
- Сопоставление выписки: «Сопоставить выписки» → «Не сопоставлено» пусто.

## Тесты

`odoo-bin -d <база> -u nj_bank_loans --test-tags /nj_bank_loans --stop-after-init`

## Известные ограничения
- Экономия — только проценты; комиссия банка и упущенный доход по депозиту не учитываются.
- Пени ищутся по тексту назначения; банк без слова в тексте не будет найден — проверять ежемесячно.
- «Стоимость дня просрочки» видна только если заполнен процент пени по договору.
- Расчёт досрочного до загрузки графика банка — оценочный.
